= ocp4_workload_low_latency_workshop - Low Latency Performance Workshop

== Overview

This workload deploys the Low Latency Performance Workshop on a Single Node OpenShift (SNO) cluster. The workshop teaches performance tuning techniques for real-time and low-latency workloads on OpenShift.

== Supported Cloud Providers

* AWS (EC2)
* Azure
* GCP
* Any platform supporting SNO

== Prerequisites

* An existing OpenShift 4.14+ cluster (preferably SNO)
* Cluster admin access
* Sufficient resources:
** Minimum 16 vCPU
** Minimum 64GB RAM
** Minimum 200GB storage

== Deployed Components

This workload installs:

1. **OpenShift GitOps (ArgoCD)** - GitOps continuous delivery
2. **OpenShift Virtualization** - KubeVirt-based VM management
3. **SR-IOV Network Operator** - Network performance optimization
4. **Workshop Documentation** - Antora-based workshop guides

== Deployment

=== Using ocp-workloads Config

Create a variables file:

.vars.yml
[source,yaml]
----
cloud_provider: none
env_type: ocp-workloads

ocp_workloads:
  - ocp4_workload_low_latency_workshop

target_host: localhost

# Optional customizations
ocp4_workload_low_latency_workshop_deploy_docs: true
ocp4_workload_low_latency_workshop_student_name: student1
----

Run the deployment:

[source,bash]
----
cd agnosticd/ansible
ansible-playbook main.yml -e @vars.yml
----

=== Direct Role Invocation

[source,bash]
----
ansible-playbook -i localhost, -c local ./configs/ocp-workloads/ocp-workload.yml \
  -e ocp_workload=ocp4_workload_low_latency_workshop \
  -e ACTION=create
----

== Removal

To remove the workload:

[source,bash]
----
ansible-playbook -i localhost, -c local ./configs/ocp-workloads/ocp-workload.yml \
  -e ocp_workload=ocp4_workload_low_latency_workshop \
  -e ACTION=destroy
----

NOTE: OpenShift GitOps is NOT removed automatically as it may be used by other workloads.

== Workshop Modules

The workshop covers:

1. **Module 1**: Introduction to Low Latency Computing
2. **Module 2**: OpenShift Performance Fundamentals
3. **Module 3**: Baseline Performance Measurement
4. **Module 4**: CPU Isolation and NUMA Tuning
5. **Module 5**: Virtual Machine Performance (using OpenShift Virtualization)
6. **Module 6**: Advanced Topics and Best Practices

== Troubleshooting

=== Operator Installation Issues

Check operator status:

[source,bash]
----
oc get csv -n openshift-cnv
oc get csv -n openshift-sriov-network-operator
oc get csv -n openshift-operators | grep gitops
----

=== HyperConverged Not Ready

Check HyperConverged status:

[source,bash]
----
oc get hyperconverged kubevirt-hyperconverged -n openshift-cnv -o yaml
oc get pods -n openshift-cnv
----

=== Documentation Not Loading

Check deployment status:

[source,bash]
----
oc get pods -n low-latency-workshop
oc get route workshop-docs -n low-latency-workshop
----
